  (`--json commits`, `--limit 30`) were not run against the API in this phase; SHIP runs it for real.

  when upstream changes; the workflow comment says to re-copy.

  and this pass is recorded below with this branch's `recordPass`. REVIEW's marker and
  `checkFixRounds`' first real use happen in the next phase.
