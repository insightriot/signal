# M6.E9 — Review

**Verdict: PASS-WITH-FIXES. All findings addressed in-phase; no fix touched non-test source beyond
markdown command files, and none changed the design.**

**This is the first REVIEW in Signal's history to run § 4.5 with all three specialists.** Two of them
were files nobody invoked until this Epic wired them, an hour before they were dispatched. All three
ran with no session context, via the dev-mode fallback.

## The result that matters

**The newly-wired agents found defects in the change that wired them, including the one that would
have shipped a false claim.** That is the wiring proving itself, and it is stronger evidence than any
test here.

| Agent | Severity found | The one that mattered |
|---|---|---|
| `code-reviewer` | 1 Critical, 6 Important, 6 Minor | § 4.5's **imperative was still singular** |
| `test-engineer` | 3 Critical, 1 High, 3 Medium | two "proof" tests were **vacuous**, one **inverted** |
| `security-auditor` | 2 Medium, 1 Low | the fallback path makes `tools:` frontmatter **inert** |

## Critical — § 4.5 said `wired` on the strength of a table row

`code-reviewer` found it: the table gained two rows and **the sentence that tells a run what to do
did not change.** It still read *"Dispatch `agents/specialists/code-reviewer.md`"* — singular, one
filename — and the dev-mode fallback named only `code-reviewer` with *"the same two inputs"*, wrong
for `test-engineer`, which takes three.

⚠ **So `security-auditor` and `test-engineer` were recorded as `wired` on the strength of a table
row with no matching imperative** — and `agent-reachability.md` opens by declaring that exact
distinction *"the whole point of this page"*: **a command naming an agent in prose is not dispatch.**
The detection rule counts a table row, so the suite agreed with the false claim.

**This is the Epic's own defect class, committed inside the Epic built to end it** — the fourth
instance this Epic, and the only one that reached a shipped artifact. Fixed: the imperative names all
three and the fallback covers all three with per-row inputs.

## Critical — the guards that were supposed to outlive the Epic could not fail

`test-engineer` proved both by mutation, with a helper that aborts if the mutation does not apply:

- **`FR7 — a newly added agent fails this suite…` was vacuous AND INVERTED.** It created a real
  undetermined agent — the exact scenario in the test's name — and **the test passed**. It then
  documented the agent correctly and **the test failed**. Green on the defect, red on the remedy, and
  a landmine for anyone who ever names an agent `brand-new-agent`.
- **`FR8 — the guard would have caught the code-reviewer double-listing` was materially false.** It
  reproduced the real `v0.1.39` double-listing and the test **stayed green**. `x + y` contains `y`;
  it was a heading-presence check wearing a regression-proof's name.

**Root cause, and the fix is structural:** the helpers closed over the module-level `page`, so a
proof had no way to run the predicate against a synthetic page without mutating shared state. Both
authors fell back to string tricks. **Every helper now takes the page text as a parameter**, and both
proofs mutate a copy, assert the mutation applied, and assert the predicate flips.

## Critical — a `wired` verdict was never checked against reality

`test-engineer` added a fabricated row — `debugger` dispatched by `commands/execute.md` § 9, a
command with **no `subagent_type` and no § 9** — and the suite returned **11 passed**. The page
asserted a dispatch nothing performs and every guard endorsed it.

Fixed: `determination()` returns `'wired'` only when the **tree** agrees (`measured.dispatched`); a
table row for an agent the tree does not dispatch now returns `'false-claim'` and fails FR7.

## Important — FR8 failed open, and would have fired falsely

Two separate defects in one line, both from `code-reviewer`:

- `[, x = ''] = split('## Not dispatched')` meant **a renamed heading produced an empty haystack and
  the guard went green over nothing.** Now throws.
- Slicing to end-of-file swept in the *"worse than unreachable"* narrative, which names
  `codebase-researcher.md` and `verifier.md` in prose — so FR8 **would have fired falsely the moment
  either was wired**, which the page's own trigger anticipates. Now bounded to the dormant section.

## Medium — the fallback makes `tools:` frontmatter inert

`security-auditor` demonstrated it from inside: running as a general-purpose sub-agent, its declared
`tools: Read, Bash, Grep, Glob` was not enforced — it enumerated the write, database and mail tools
it could reach and used none. **`init.md` already solved this**, embedding *"You are read-only"* in
its scanner prompts; `review.md` had no such sentence. Fixed, and the file now says plainly that this
is a prose ceiling on an unconstrained agent, **not enforcement**.

Related, from both agents: **`test-engineer` declares `Write, Edit` and its body tells it to write
tests.** At REVIEW that would invalidate the diff the other two were handed and stale the suite result
VERIFY recorded, with the edits reaching SHIP unverified. The dispatch row and a new paragraph now say
report-only.

## Important — the anchor and the artifacts disagreed with themselves

- **`ADHERENCE-LOG.md` pinned `3225bda`, at which its own numbers do not reproduce.**
  `adherence-ceiling.js` measures the working tree but pins `git rev-parse HEAD`, so a run made
  before committing names the previous commit — `adherence-run.js`'s own AC4.3 failure: *"the record
  would name a state nobody can return to."* Regenerated at the tip.
- **`STATE.md` said `phase: DISCUSS`, `completed_phases: []`** beside a HEAD whose commit message
  read *"M6.E9 VERIFY"*. Corrected.
- **`M6.E9-DETERMINATIONS.md` still claimed 12 wire / 8 dormant / 1 cut** against a shipped 2 / 19 /
  0, giving `codebase-mapper` a different verdict in each of two committed artifacts. Resolved with a
  delta box; the proposal is kept unedited, because a proposal silently rewritten to match the
  outcome is not a record of a decision.

## Also fixed

well as a trigger, and five entries reading `**Trigger:** same.` were given real ones; a new guard
requires trigger *text*, not the marker.

## Not fixed, and named

- **FR5 has no regression guard.** `plan.md` deliberately preserves the old imperative as a labelled
  quotation, so the obvious assertion would fail on the correct file. A guard would have to assert
  the string appears *only* inside the historical block.
- **FR3 remains NOT EXERCISED.** No `cut` verdict was issued; a cut agent left on disk still passes.
