| B88 | `fixed` | **P1** | **Signal is branch-blind: nothing creates a branch, nothing checks one exists, and `/sig:ship`'s "create a pull request" is unreachable once every commit has landed on the default branch.** Reported from a **`eval-project-A`** slice (VOICE1/T7) where five commits of real code reached `main` with no branch and therefore no PR — CI ran *after* each push instead of gating it, and `git push` printed *"Bypassed rule violations"* and succeeded because `enforce_admins=false`. **Verified against Signal's own files, not accepted on report** — and the truth is broader than the report claimed: `grep -rln 'git branch --show-current|rev-parse --abbrev-ref' commands/ tools/lib/` returns **nothing**. Not one of 20 commands and not one library module reads the current branch. Three confirmed sites: (a) **`commands/execute.md` contains zero occurrences of the word "branch"** — step 2 says "create an atomic git commit" and commits to whatever branch you happen to be on; (b) **`ship.md` §3 (`:94`) is a bare instruction**, *"Create a pull request with:"*, with no precondition that a PR is still possible — if HEAD is the default branch there is nothing to open one from, and the step fails silently; (c) **the Exit Criteria (`:198`) reads `- [ ] PR created with description, test plan`** — a checkbox satisfied from the felt sense of having shipped, never from a PR URL. That is exactly the `CLAIM-INTEGRITY-ANALYSIS.md` class. **The sharpest part is the location:** `ship.md:116` is the paragraph that *removed* the direct-to-main exemption (`D-M5E17-5`) and states in prose that a change *"does need a branch, a PR, and a green suite"* — while the same file provides no mechanism to make that true and no check that it happened. **The file that states the rule still supplies no enforcement**, which is the precise shape `D-M5E17-5` was filed to end (thirteen releases, exactly one PR). **Fourth instance of the family**, three of which are verified in this repo: `B41` (four commands never called `transitionPhase`, phases unrecorded for eleven releases), `B43` (`ship.md` claimed a SHIP date `transitionPhase` structurally cannot write — SHIP is terminal), `D-M5E17-5` (the self-granted exemption). **Remediation, three candidate sites, not yet chosen:** (1) **`/sig:execute` phase entry** — it already calls `transitionPhase(baseDir,'EXECUTE')` at a guarded point (`execute.md:46`), so asserting a non-default branch there is the earliest moment that matters and makes a slice unable to *begin* on the default branch; (2) **`/sig:ship` §3 as a precondition, not an instruction** — halt when `HEAD == default`, the same remedy `B48` applied to `transitionPhase`, which *"now also refuses to record a phase that produced no artifact, so the text and the code agree rather than one relying on the other"*; (3) **the Exit Criteria read from a PR URL**, not a checkbox. **(2) is the one that also catches the human half** — a halt forces the conversation the reporter chose to have with a summary file instead. **Live in this repo today, and only masked by habit:** every branch in this session was created because `CLAUDE.md` says to and the operator remembered — the same *depends-on-remembering* failure mode as `B87`, filed hours earlier. **Found 2026-08-08**, reported by the `eval-project-A` maintainer, confirmed here by reading the command corpus. **FIXED 2026-08-08** — `tools/lib/branch-guard.js`, wired at all three candidate sites rather than one, since they catch different failures: `/sig:execute` refuses to *begin* on the default branch, `/sig:ship` refuses to ship from it, and the Exit Criteria is filled by `formatPrEvidenceLine` from a real PR URL instead of being ticked. **Hard stop with `--allow-default-branch` as the deliberate way past**, and **tier-gated to FEATURE + FULL** — derived from `references/tier-definitions.md`, not from taste: SKETCH has *"Gates off"* and SPIKE's output is *"A findings document… Not a PR"*, so halting a spike for lacking a branch would have been a fresh `B89` (one instruction contradicting another) shipped inside the fix for it. **The guard does NOT reuse `state.js`'s default-branch resolution**, which falls back to the literal `main`: correct for an advisory banner, wrong for a halt, because the same fallback produces a false halt (no remote) and a false clear (a `master`-default repo) from one line — pinned by a `master`-repo regression test. Four outcomes stay distinguishable (`state-drift.js`'s contract): `cannot-determine` never renders as clean. **Two defects found in this fix's own work, both by the M5.E15 harness:** the new precondition restated the phase-entry rule, putting a directive **outside the `B41-phase-entry` canary's deletion scope** — the `B55` shape, in the release that cites `B55`; and the module header's historical citations tripped the leak walk, fixed by rewording rather than by allowlisting the file, since the allowlist has no per-line grain and an entry would have blinded the walk to any real directive the module acquires later. 2330 → **2361 tests**. |
