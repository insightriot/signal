## M5.E7's changelog section is invisible to `/sig:update` · **RESOLVED 2026-08-18**


The heading was relabelled from `## [Unreleased] — 2026-07-26 …` to `## 2026-07-26 — The v2 direction audit (M5.E7) · analysis only, no version cut`, which was the actual defect: a section that said *unreleased* about finished work.

**The invisibility itself turns out to be correct, not a bug.** The entry's own first line says *"No code shipped, so no version was cut."* Nobody updating between two versions ever received this, because there was nothing to receive — so `changelogBetween` skipping it is the right behaviour, and giving it a version number would have invented a release that never happened. That would have been a false published fact, in the file this week's work exists to keep honest.
