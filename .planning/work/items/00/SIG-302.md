Two small things found in M6.E16's VERIFY loops.

1. `npm run lint` runs `eslint tools/ plugin/tools/` and so never lints `tests/`. Linted by hand, `tests/unit-records-import.test.js` (around line 334) has a `no-control-regex` error. CI runs the same script, so a lint error in a test file is not caught.

2. The Closed section of `work/EPICS.md` sorts by the close event's date. The 47 units closed at Signal's cutover all carry the cutover date, so they come out in ID order with legacy and dropped closes mixed, not by when each shipped.
