A guard whose local signal is clean and whose CI signal is red trains the operator to treat the local run as authoritative when it is structurally blind. **Fixed 2026-08-21:** the walk is now tracked **plus** `ls-files --others --exclude-standard`, i.e. the set a commit would actually carry; `.gitignore` still excludes scratch and build output, so nothing noisy comes in. **Proved in both directions:** an untracked file carrying the collision fails the guard, and deleting it passes — run before and after in the same step. ⚠ **CI was never blind and is not the thing that changed** — this closes the gap between what a developer sees before committing and what the gate sees after.
