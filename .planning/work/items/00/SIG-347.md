`rewriteTarget` (`plugin/tools/lib/work-links.js:43`) calls `posix.relative(toDir, abs)` on paths relative to `.planning/`. `posix.relative` resolves relative paths against `process.cwd()`, so a target that climbs out of `.planning/` comes out wrong when the process runs from a folder whose name matches the climb. Reproduced 2026-10-19: `regenerateViews` run from `plugin/` turned `../plugin/references/agent-reachability.md` into `references/agent-reachability.md` in `BACKLOG.md`; run from the repo root it is correct. Found at M6.E17 SHIP, when PR #304's CI failed `work-views-fresh`. Every write that regenerates views (`/sig:item`, closes, `closeEpic`) inherits it. Fix: do the relative arithmetic on a fixed absolute anchor, never the process cwd, with a test that runs from a subfolder.
