A same-phase re-entry (VERIFY→VERIFY, REVIEW→REVIEW) records the phase as left, so it goes through `assertLeavingArtifactExists` (`B48`). VERIFY writes its report at Step 5 and REVIEW creates its report when § 4.6 appends the pass heading, so a session that dies before then cannot re-run the phase, and every other route out throws too. The error suggests a stub report, which is the false "phase finished" record B48 exists to stop. **Present on `main` before M6.E18**, which reverted to that rule (`D-M6E18-9`). Options: skip the artifact check when `leaving === nextPhase` (a re-entry is not a claim the phase finished), or count re-entries somewhere other than `completed_phases` (state-schema rule 2 also forbids an in-flight phase there). Three fix rounds of M6.E18 changed this rule and each opened a new hole: design it before coding it.
