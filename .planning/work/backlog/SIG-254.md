Found 2026-10-01 by a dry run of /sig:docs-migrate on eval-project (a production project; dry run only, nothing applied). Reproduced in memory on file NAMES only, no project touched.

deriveUnits (plugin/tools/lib/work-units.js) over the six files of one slice:
PLAN-SLICE-SSO.md, PLAN-SLICE-SSO-RESEARCH.md, PLAN-SLICE-SSO-VALIDATION.md, SLICE-SSO-PROGRESS.md, SLICE-SSO-REVIEW.md, SLICE-SSO-VERIFICATION.md
returns unit SLICE-SSO with FIVE files and leaves PLAN-SLICE-SSO.md in ungrouped. The prefix form PLAN-<unit>-RESEARCH.md is recognised; the bare prefix form PLAN-<unit>.md is not.

Consequence: planArchiveMoves (archive-tree.js) moves the five and leaves the main plan live, splitting one slice across live and archive, which is the exact failure B82 was closed for (B82 was a different cause: planArchiveMoves not using deriveUnits at all). The fixture to add is these six names, next to the existing split-pairs fixture in tests/work-units.test.js.
