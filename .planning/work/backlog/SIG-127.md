| B127 | `confirmed` | P2 | **A live BACKLOG row whose heading says a PHASE is done reads as a DISCHARGED row — `/sig:advise` stopped seeing the in-flight `M6.E3`.** `backlog.js` `DONE_WORD_RE` (matches `**…DONE…` / `SHIPPED` / … within 80 characters of a bold marker, ignoring case) is case-insensitive, so the heading marker `**IN FLIGHT — EXECUTE done 2026-09-27, VERIFY next**` matched `done` and the row was filtered out of `live` (`advise-corpus.js:98`). Found 2026-09-27 at `M6.E3` VERIFY, by accident: rewording the marker made the row live again and `TRIGGER_MET_MEASURED` moved 2 → 3. **The false-done direction of the class `M6.E3` is about**, in the tool that ranks what to work on next — the Epic in flight was invisible to it for however long the marker read that way. Not fixed here (fix lane or the status redesign, `D-M6E3-16`); the marker was reworded to avoid the word, which hides the symptom only for this row. |
