## `attention` is undocumented in profile-schema.md

**Status:** needs-triage

`attention` is a live PROFILE.md field that `profile-schema.md` does not document. Found 2026-08-23 while writing `M6.E4-PROFILE.md`. `ATTENTION_LEVELS` (`attended`/`checkpointed`/`unattended`) is exported from `tools/lib/profile.js` and `attentionFor` derives it from `gate_strictness` — but `references/profile-schema.md`, which `tier-definitions.md` points to as "the full PROFILE.md schema", has ZERO occurrences of the word. It is documented only in `phase-gates.md` and `anti-rationalization-forms.md`. Same class as `B108` (v0.1.31 moved confirm cadence to `attention` and left six command files describing the old dial) — the authoritative schema doc was one of the surfaces that release did not sweep. Cost: anyone writing a PROFILE.md by hand from the authoritative doc cannot discover the field, and cannot learn that omitting it derives a value rather than leaving it unset. Concretely: this session's first draft asserted `light` derives `attended`; it derives `checkpointed`, and the schema doc offers no way to check that.
