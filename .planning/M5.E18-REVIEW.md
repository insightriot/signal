## Security Findings — `security_audit: full`

Threat model: a local CLI/plugin processing `.md` files in a repo the user runs it against. No
server, no network, no user accounts, so most of OWASP's web Top 10 is not applicable; the live
categories are injection/traversal, insecure design, and vulnerable dependencies.

| Check | Result |
|---|---|
| **Path traversal (A01/A03)** | **PASS.** `isSafeUnitName` requires an alphanumeric first character (rejecting `.`, `..`, `.hidden`, `/abs`), excludes `/` and `\` by charset, and rejects `..` anywhere separately so `.` stays legal inside `M4.5.E1` / `v0.1.6`. `deriveUnitArchiveDir` throws as a second layer. 12 adversarial fixtures. |
| **Symlink escape at write time** | **PASS** — verified by reading `archive-tree.js:399`, which does the lexical check, the planning-root symlink check, and `realpathNearestExisting` on the dest directory. `path-confine.js` names `archive` as the exact vector; it is covered. |
| **Command injection** | **N/A** — no `exec`/`spawn`/`execFile` in any new module (grepped). |
| **SSRF / network** | **N/A** — no `fetch`/`http` in any new module. |
| **Secrets exposure** | **PASS** — no `process.env` reads; nothing new is logged that carries file contents beyond a unit name and a one-line reason. |
| **ReDoS (A05)** | **PASS.** Every new regex is linear with no nested quantifiers: `/^[A-Za-z0-9][A-Za-z0-9._-]*$/`, `/-([A-Z0-9]+)\.md$/`, `/\b(PASS\|FAIL)\b/`, `/verdict\b/gi`, `/[\s>*_\`~#-]+$/`. |
