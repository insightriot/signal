## Important Issues — six, all found and closed in-phase

### 1. The artifact said the ranking read five sources. It reads one. *(reviewer)*

`renderArtifact` printed `**Read:** BACKLOG.md · BUGS.md · retrospectives · STATE/closure ·
milestone rows` directly above a ranked list. `readCorpus` genuinely reads all five; **every ranking
input reads only `sources.backlog`.** A maintainer sees that header and concludes open bugs and the
current phase were weighed. They were not.

This is [`CLAIM-INTEGRITY-ANALYSIS.md`](../analysis/CLAIM-INTEGRITY-ANALYSIS.md)'s class — a
completeness claim written from the shape of the work rather than the artifact — **inside the
command built to stop making them.** It is the single sharpest finding of the Epic.

**Fixed by making the claim true, not by widening the ranking:** a `**Consulted by the ranking:**`
line naming `BACKLOG.md` only, stating plainly that no current input reads the other four. Wiring
them in is a sixth ranking input and a plan change — **design impact, which is FAIL, not
fix-in-phase.** Deferred to the backlog rather than smuggled in here.

### 2. The artifact stated two different counts for the same row *(reviewer)*

Reproduced in the advisory this repo had **already generated**: the recommended section said
`Passive OBSERVATIONS.md capture` had *"1 rows scored above it"*; the declined section said *"5 rows
scored above it"*. Same row, same document. The contrast clause passed the **recommended** index —
always 1 — where it needed the row's rank in the declined pool.

A self-contradicting count in a document whose entire claim is that its claims are checkable. Fixed
to compute the rank exactly as the declined section does; both now read 5. Three grammar defects in
the same sentence went with it: `1 rows`, `which demoted by`, and `Ranked on its written trigger has
fired`.

### 3. `readCorpus` reported reading a corpus that did not exist *(mine)*

With **no `.planning/` at all**, the return was `checked: ['retrospectives']`. Four sources honestly
said they could not look; the fifth claimed it had. Exactly what this module's own docblock forbids
— *"an empty result is a claim; a null plus a reason is the truth"* — inside the module that quotes
it. `enumerateRetros` returns `[]` on ENOENT, right for **its** contract and wrong as an answer to
*"did you read the retrospectives?"*

Guarded on the planning directory existing. **Both directions asserted:** absent → cannot-check,
existing-but-empty → checked with zero records. ⚠ **The test that was supposed to cover this passed**
— it replaced `.planning/` with a *file* (ENOTDIR, which throws) and never tried it *absent* (ENOENT,
which is swallowed).

### 4. A test that could not fail *(reviewer)*

*"Every declined row carries a reason"* used `find(l => l.includes(row.text))`, which takes the
**first** line mentioning the row. For the contrast row that is the *Recommended* section's contrast
sentence — which also matches the input-name regex. **Deleting the reason from that row's declined
bullet left the test green.** Both `find` calls now anchor on `startsWith('- **' + text)`.

**Third test in this Epic that passed while covering the wrong thing** (after the input-5 wiring gap
and the ENOTDIR/ENOENT swap). That rate is the finding, not the three instances.

### 5. Two throws escaped a contract that promises a reason *(reviewer — and it refuted my measurement)*

`writeArtifact` documents `{status, path, reason}`; two real conditions made it **throw past
`runAdvise`**:

| Case | Condition | Before |
|---|---|---|
| B | symlinked `.planning/` **plus a backlog with no live rows** | threw at `assertRealInsidePlanning` |
| C | ordinary `.planning/`, `chmod 555` | threw `EACCES` out of `atomicWrite` |

⚠ **I had measured this as unreachable and written that into
[`M6.E7-VERIFICATION.md`](M6.E7-VERIFICATION.md).** My reasoning — *"every citation points into
`.planning/`, so the citation gate refuses first"* — is sound and **presumes at least one citation
exists.** An empty backlog produces none. **Case C needs no symlink and no unusual corpus at all**: a
read-only mount or a full disk reaches it on an ordinary run. I reproduced both before accepting
them; the VERIFY artifact is corrected in place.

Both now return `{status: 'skipped', reason}`. A residual, same class: `verifyCitations` let `EACCES`
out of a documented `{ok, resolved, unresolved, truncated}` — `existsSync` passing is not the same as
readable. Wrapped.

⚠ **I did NOT take the reviewer's fix for the second half of that, because it does not work.** The
suggestion was that the same wrap also covers a FIFO. **A FIFO never throws — it hangs inside the
`await`, so the catch never runs.** The guard had to move *ahead* of the read and widen from
`isDirectory()` to `!isFile()`, refusing FIFOs, sockets and device nodes before anything opens them.
Said so to the reviewer rather than quietly implementing something different. The test notes that if
it ever times out instead of failing, the guard is gone.

### 6. The only output the user sees had zero tests *(reviewer)*

`commands/advise.md` says *"Print `formatAdviseSummary(result)`"*. **No test imported it and no other
module called it** — its `skipped` branch, its cannot-read warning and its written/unchanged wording
were all unexercised. The untested user-facing renderer, in an Epic whose thesis is that a
computed-then-unread value is `B39`'s shape. Four tests now cover every branch; the `skipped` branch
matters most, because the two new reasons added in this phase flow straight into it.

## A fix I wrote, tested, and deleted

The reviewer flagged the count gate as doing no work at zero claims (`0 < 0` is false). I added
*"refuse when rows exist and nothing was claimed"* — **and my own new test then failed against the
old message, which is how I learned the branch is unreachable.** `rankRows` **partitions**: every row
lands in `recommended`, `rest` or `dropped`, and `declined` is `rest + dropped`, so `claims === 0`
implies there were no live rows and nothing to cite. The vacuity is real and **harmless**; the guard
would have been **dead code shipped to look like rigour.**

Removed, and replaced with the partition invariant as an assertion — so a future change that drops a
row makes the vacuity reachable and turns the test red. Recorded because deleting a fix is the part
that normally goes unwritten.
