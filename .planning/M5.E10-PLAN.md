## What this Epic does for the first time — and why S1 is wave 1

**`tools/lib/evict.js`'s `FR_ID_RE` / `AC_ID_RE` have never been used to enumerate requirements.**
They exist for a different job — proving no discrete token was lost during eviction — and FR1 is
about to repurpose them as the authority on *"what requirements exist."* That is existing machinery,
built for one purpose, about to be run for another.

**It is already known to be wrong for the new purpose.** `\bFR\d+[a-z]?\b` does not match `NFR1` —
the word boundary fails mid-token — and this Epic's own REQUIREMENTS declares **five NFRs**. Consumed
unchanged, FR1 would emit a coverage report that silently ignores every non-functional requirement
**while reporting itself complete**: this Epic's defect class, in this Epic's first deliverable,
shipped by the Epic chartered to kill it.

**Second first:** `examples/sandbox/` was built at M5.E19 for the closure/archive surface, and its
README promises shapes get added as the commands needing them get worked on. **No command has ever
added one.** This Epic is the first to test that promise.

**Third:** `validateRetroContent`'s locked-headings + byte-threshold mechanism has only ever
validated retrospectives. FR3 applies it to a second document class for the first time.

**Therefore S1 is wave 1** — prove the extractor before anything consumes it. If the extraction is
wrong, it breaks against a unit test rather than against a coverage report that everyone believes.

*What this section deliberately does not name:* the coverage diff itself, the template, the new
checks. **Newly-authored things have no history to be wrong about.** The risk is in the machinery that
already exists and has never been run for this purpose.

| Task | What | Complexity |

- **AC S1.1** — one module is the only place a requirement ID is recognised; `evict.js` calls it.
  *(Kills RK2 — `B82`'s shape, two implementations of one concept.)*

- **Test strategy:** pure-function unit tests, TDD throughout. S1.t2's RED is the whole point of the
  slice and must be demonstrated, not asserted.
