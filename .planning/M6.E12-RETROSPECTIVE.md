## What assumptions broke

- **"The digest is capped."** Recorded as verified at VERIFY; it held only for groups that could be
  trimmed. 3,000 P1 bugs made 563,616 characters. The tests grew only trimmable groups — a claim
  written from the tests' shape, not the property.
- **"Every read goes through the confined reader."** Said in the pass-1 commit message; true for the
  reads I had touched. Pass 2 found `readState` and closure; pass 3 found the discharge path. A claim
  about *every* call site needs a search, not a memory of the edits.
- **"Confined to the project root" is safe.** The root holds `.env` and `.git/config`.
- **26 acceptance criteria.** There were 22; the first VERIFY draft had the wrong total, caught by
  re-adding before commit.

## What surprised us

- **The user's one question was the best review of the proposal step.** "Are there any natural
  dependencies?" found what three reviewers would not have looked for — they review code, not the
  judgment it hands the user.
- **Fixes produced the findings.** Pass 2's three introduced defects and pass 3's two all came from the
  previous pass's fixes — pass 2 widened `quoteSafe`'s line-break set without reordering it, and that
  rebuilt the very marker it strips.
- **The review never converged on hostile inputs.** Normal-use findings shrank each pass; the
  hostile-repository surface (links, pushed branches, crafted text) produced new routes every time.

## What we'd do differently

- **Name the threat model at DISCUSS.** "A cloned repository and a pushed branch are untrusted input"
  — or "not in scope" — would have bounded three review passes. Nobody decided it, so every reviewer
  decided it, generously.
- **Fix classes on the first pass, not the second.** Pass 1 fixed routes; pass 2 re-found the class.
- **Grep for every caller before writing "every read".**
- **Put a property test (inputs grown in every group) next to any cap.**

## Anti-rationalization moment

At pass 3, "fix everything and run a fourth review" was available and looked rigorous. The evidence
said it would not converge: each pass had found new routes into the same family. Saying that out loud
and handing the decision to Brett — with the residue filed and its threat model written down — was the
honest version; a fourth pass would have looked thorough and mostly measured my stamina.
