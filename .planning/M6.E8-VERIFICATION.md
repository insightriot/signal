## What this could not establish

**1. Two of the new assertions can never have been red, and one whole requirement is a non-change.**
Nyquist is `strict`, and the evidence form used is attestation (form *b*): every test file below was
written and **run red before** the implementation that turned it green, in the task order in
[`M6.E8-PROGRESS.md`](M6.E8-PROGRESS.md) — t1.1 (6 red), t1.2 (4 red), t1.3 (1 red), t1.4 (6 red),
t2.1 (5 red), t2.2 (5 red), t3.1 (9 red), t3.3 (2 red). **t3.2 never went red and structurally could
not**: `AC2.1′` and `AC2.2` assert that `BLOCKED_RE` is *unchanged*, a property that already held, so
reaching red would require first building the widening this Epic refused. They are regression guards,
not proofs. The same is true of `AC3.2` (mentions never drop) and the `NFR2` import assertion: both
guard a property that was already true. **Four assertions in this Epic prove that nothing broke, not
that something was built.**

**2. The ranking is not shown to be *better*, and no instrument here could show it.** The
requirements said this in advance and it survives VERIFY unchanged: `LOOP-GOAL-DIRECTION.md` measured
the best honest selection rule over these rows at 77% precision / ~37% recall. This phase established
that the inputs fire where they were measured to fire and nowhere else. It established nothing about
whether the resulting five rows are the right five.

**3. The `####` depth gap in input 3 is untested because it is unreachable here.** `AC3.3` pins zero
discharged rows on this repository, and the plan records why that zero is not reassuring:
`backlogDischargeStatus` parses at `maxDepth: 3` while the advisor reads at 4, so a `####` row led by
a closed unit is invisible to the input. **Zero is what both a working check and a blind one return
on this corpus.** Filed, unfixed, cross-referenced in `commands/advise.md`; fixing it belongs to the
check, not here.

**4. The live-measurement pins are only as honest as the next person's reaction to a red.** They
assert equalities against a file that changes, and their failure text asks for a re-measurement. A
reader who instead edits the constant to match gets a green suite and a vocabulary nobody re-read.
Nothing here can prevent that; the failure message is the whole defence.

**5. Only one corpus was exercised end to end.** `runAdvise` ran against this repository. The
eval-corpus projects were **not** run — corpus runs are read-only and this Epic's effect is on
`BACKLOG.md` vocabularies that only this repository's file exhibits. The fold and bug-discharge
vocabularies are therefore measured on **one** real file, `n=1`, and `declaresNotLiveWork`'s own
history is the warning: its docblock counts were correct for one week and wrong thereafter.

**6. The new advisory carries no commit anchor.** [`BACKLOG-REVIEW-2026-09-14.md`](BACKLOG-REVIEW-2026-09-14.md)
was written during this phase and its 53 citations are true at `60b9f1f` and nowhere else; nothing in
the file says so. That is `B119`, unfixed, and this phase has now produced a second artifact carrying
it. The Outcome-instrument failure in the Verdict is `B118` — the same family, one level up: **an
advisory is a claim about one branch's corpus at one commit, and neither fact is written in it.**
