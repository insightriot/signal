### Deviations, surfaced not absorbed

4. **FR2 was redesigned at Wave 2 entry — requirements rewritten before any code.** Drafts 1
   and 2 both recorded the phase being **entered**. Implementing it exposed that this corrupts
   the field: `completed_phases` would list the phase in flight, so `resume.js` counts an
   unfinished phase as done and **`isEpicCloseByState` fires a phase early** — the detector
   M4.5.E9/`B26`/`B30` spent three Epics getting right. `B43`'s real defect is narrower:
   recording the phase **left** is correct, and the gap is that **SHIP is terminal**. The fix
   is an addition (`completePhase`), not an inversion.
5. **My first trim implementation broke its own idempotence**, and the AC5.5 test caught it:
   the trim empties the live list, which erases the evidence the same-day guard reads — so a
   re-invoked ship re-recorded SHIP into the emptied list and archived a second near-empty run.
   Fixed with a second guard (`phase: SHIP` + empty live list = already closed). **The failure
   mode was only visible because idempotence was speced as an AC rather than assumed.**
6. **`state.js` duplicates `evict.js`'s archive-path rule** — importing it back would be a
   cycle. Allowed **only** because a drift guard fails the moment they diverge; a silently
   diverging second implementation of a path rule is the schism `state.js:100-108` records as
   already burning Signal once.
