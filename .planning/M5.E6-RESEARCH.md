## FR5 — Retro gate fires on a fresh REVIEW→SHIP flow (B30)

**`ship.md` flow:** Step 0.5 (`ship.md:27-43`) calls `shipFR1Check({state, profile, milestoneContent, baseDir})` — this is where the retro gate + `{isEpicClose}` are decided, and **§5.5/§6/§6.5 (evict/retro-index/inbox-sweep) are ALL gated on `{isEpicClose:true}`** (:106,126,132). Step 5 (`ship.md:91-102`) is the ONLY place `phase` is written to SHIP (`transitionPhase(baseDir,'SHIP')`), and it runs near the *end*. So on a fresh flow, at Step 0.5 `phase=REVIEW` → gate skips → **AND evict/index/sweep are silently disabled too** (wider blast radius than just the halt).

**Predicates:** `shipFR1Check` (retrospective.js:751-829) → `isEpicClose = isEpicCloseShip(state,milestone) || (rowStatus===null && isEpicCloseByState(state,profile))`. `isEpicCloseByState` (:410-420) requires `current_epic` set **AND `phase==='SHIP'`** AND `completed_phases` ⊇ tier-required pre-SHIP phases (`PRE_SHIP_PHASES = [DISCUSS,PLAN,EXECUTE,VERIFY,REVIEW]`, :24-27). Fresh flow fails the `phase==='SHIP'` clause → `{skipped:true}`. Layer-2 `checkProposedStateWrite` (:473-519) is hard-gated on `phase==='SHIP'` and only fires on an Edit/Write **tool** call — the programmatic `transitionPhase` (`fs`/`atomicWrite`) bypasses it, so **Layer-2 is NOT a backstop here**.

**Recommendation — approach (c) done right: in-memory synthesized post-transition state, persist NOTHING.** Literal spec-(c) ("transition then re-check") is a trap — persisting `transitionPhase('SHIP')` before the gate *is* approach (a)'s persist-on-halt smell. Instead, inside `shipFR1Check`, when about-to-close, evaluate `isEpicCloseByState` against an **in-memory** `{...state, phase:'SHIP', completed_phases: dedupeByPhase([...completed, `${state.phase} (today)`])}` (simulates what `transitionPhase('SHIP')` would produce) and persist nothing until the gate passes. `isEpicCloseByState` stays byte-unchanged (its unit tests + the Layer-2 hook untouched); `ship.md` needs no reordering.

**Engage guard (tightly gated — this is what neutralizes false-fire):**
```
shipsAtAll  = !phases_skipped.includes('SHIP')               // SPIKE excluded — LOAD-BEARING
lastPreShip = PRE_SHIP_PHASES.filter(p=>!skipped.has(p)).at(-1)   // FULL/FEATURE→REVIEW, SKETCH→VERIFY
aboutToClose = shipsAtAll && state.phase === lastPreShip && rowStatus === null
```
Only when `aboutToClose` synthesize + evaluate. **`shipsAtAll` is load-bearing:** without it SPIKE (`phases_skipped:[REVIEW,SHIP]`, lastPreShip=VERIFY) would engage at `phase:VERIFY` and wrongly halt (breaks `:339`). `SHIP ∉ PRE_SHIP_PHASES`, so it's a *separate* clause. Frame to PLAN as "disciplined-(b) that earns (c)'s recovery property."

**Recovery win (why c > a):** on a halt (missing retro), (a) leaves STATE persisted at `phase:SHIP` → `/sig:resume` mis-orients as "shipped"; (c) persists nothing → STATE stays `REVIEW`, recovery-clean. (c) also fixes §5.5/§6/§6.5 gating on the fresh flow and is unit-testable in one function.

**Tests (`tests/ship-fr1.test.js`):** AC5.1 RED = fresh state `phase:REVIEW`, **REVIEW NOT yet in completed_phases** (genuine fresh), no-row, no-retro → `{halt:true, NO_RETRO_FILE}` (fails on `main` = skipped). AC5.2 = write retro → `halt:false` **AND `isEpicClose===true`** (the isEpicClose assert is required — it's what re-enables §5.5/§6/§6.5). AC5.3 no-false-fire = maintained-pending-row skips, SKETCH-short skips, mid-flow `phase:EXECUTE` skips. **SPIKE inertness** (`:339`) = the `shipsAtAll` witness (fails if guard omitted). **Two existing tests are the fix surface, not regressions:** `:361-374` **inverts** (its `phase:REVIEW`+REVIEW-completed fixture now synthesizes to close → `halt:true`; update assertion + comment→B30); `:339` stays green **only with** `shipsAtAll`.
