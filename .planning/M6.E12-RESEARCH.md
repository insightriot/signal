# M6.E12 — Research

Done by angle, in this session (the research agents are dormant: `references/agent-reachability.md`).

## Codebase

- **`runAdvise` is one call today** (`plugin/tools/lib/advise.js:699`): read corpus → rank → render →
  stale-read guard → citation gate → write. The new flow has a model step in the middle, so it splits
  into **prepare** (digest, no write) and **write** (validate a proposal, render, gate, write), with the
  ask and the record after.
- **Citations have one structural position:** a trailing `— evidence:` region on a claim line,
  produced only by `cite()` (`advise.js:180`) and read only by `extractCitations`
  (`citations.js:75`). Priorities and covered rows must render through `cite()` on claim lines; the
  digest's own references must NOT, or the gate would count digest text the advisory never claims.
- **`quoteSafe` already neutralizes markers and newlines** in quoted text (`advise.js:195`). Model-written
  `title` / `why` are quoted text for this purpose and go through it.
- **The gate asserts a count** (`advise.js:764`): `resolved >= recommended + declined`. The new count is
  `priorities + covered rows + appendix rows` (every appendix row still carries its row citation).
- **The stale-read guard** (`findStaleRowCitations`, `advise.js:665`) re-reads each cited row line and
  checks it still carries the row. It takes `ranked.recommended + declined`; it must take every row the
  new artifact cites.
- **Age lives in exactly three places:** `ageDays` in `rankRows`' scoring, the sort key, and the two
  reason builders (`recommendReason`, `declineReason`'s `beatenBy.push('age')`). `ISO_DATE_RE` and
  `daysBetween` become unused and are removed with them.
- ⚠ **`FORBIDDEN_VERBS` is `['chosen', 'selected', 'decided']`** (`advise.js:76`), asserted absent from
  the labels and the artifact by `t3.2b` — FR6 of `M6.E7`: the advisor proposes and never selects.
  A recorded pick IS the user's decision, written after the user makes it, but a section titled
  *"Chosen"* would trip the guard and blur the line the guard protects. **The pick is recorded under
  *"Picked by you"*** and `t3.2b` keeps asserting the renderer never claims a decision. Amends the
  wording of `D-M6E12-8`; the behaviour is unchanged.
- **`ADVISOR_SOURCES`** (5 since `B118`) and the `checked + cannotCheck` invariant are reused for the
  digest's corpus half. The digest adds sources the ranking never read (vision, milestone theme,
  retrospectives, questions, inbox count); they get their own list, `DIGEST_SOURCES`, with the same
  invariant, so neither list's count claim is diluted.
- **`/sig:drive`'s backlog order is not age** (`rankBacklogRow`, `drive.js`): it sinks headings that
  read as prose sections and then ties on line number. It stays as the "something else" order. That
  is shape, then file order — `D-M6E12-11`'s "file order" is read that way.
- **Work store:** `listItems` gives type/priority/theme for items; bugs by priority come from
  `BUGS.md`'s rows via `walkBugEntries` (already in `readCorpus`), which works with or without the store.
- **Retrospectives** carry `## What to feed back into Signal` and `## What we'd do differently` in
  every recent one (`M6.E11`, `M6.E8`, `M6.E3`). Other projects' retros come from the same template.

## Risk

- **Context budget.** A digest that inlines whole files would crowd out the work it is meant to help
  choose. Cap per source (rows: heading + 200 chars; retro sections: 1,200 chars each; total ~12 KB)
  and say in the digest when something was cut.
- **Model output is untrusted input to the renderer.** A `why` containing the evidence marker or a
  newline could forge a citation or document structure. `quoteSafe` everything model-written; validate
  `evidence` tokens against the citation grammar before rendering.
- **Covered rows that do not exist.** A priority may name a row id that is not live. Validation refuses
  it, naming the row, rather than rendering a citation to nothing.
- **Non-determinism makes tests tempting to skip.** Tests pin the contract with fixture priorities; the
  real synthesis is exercised once in wave 1 on this repository and recorded.
- **Same-day re-run** would replace an advisory holding a pick. `-N` naming (AC4.3) prevents it; the
  doc-budget exemption pattern `BACKLOG-REVIEW-*` still matches.

## Prior art

- `M6.E7`'s retrospective: claims written from the shape of the work. The priorities' `evidence` must
  be cited rows and lines the model actually read, which the gate checks for existence and the
  stale-read guard checks for content on row citations. Lines cited outside `BACKLOG.md` are checked
  for existence only — the published limit, restated in the artifact.
- `M6.E3` (Jev) established *advice with receipts, never a refusal* for model judgment. The priorities
  are the same posture: judgment, cited, picked by a person.
