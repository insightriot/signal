### F1 — Completeness gap found and closed

**AC1.3 (isolation) had no test.** The harness runs a real agent that writes files; the obvious
catastrophic bug is pointing it at the invoking project and letting an agent edit Signal's own
`.planning/`. Assigned to **S2.t1** with an explicit confinement assertion reusing
`path-confine.js`. *An untested isolation guarantee on a process that writes files is the one gap
here that could destroy work rather than merely mislead.*

### F2 — The testability asymmetry, stated rather than glossed

**Slices 1 and 4 are fully suite-testable.** The classifier is deterministic; the log format and
the checklist line are static.

**Slice 3's core is not.** Its output depends on a paid, nondeterministic external process — that is
precisely why D-M5E8-1 kept it out of CI. So the suite can test the harness's **mechanics**
(mutation applied to a copy, N runs executed, spread computed, inert-verdict path reachable) using a
**stub agent**, and cannot test the **verdicts**.

**The honest boundary:** a stub-driven test proves the harness *computes correctly*, never that its
answer about a real agent is *true*. Recorded here because the alternative — a green suite implying
verified adherence — is the exact failure this Epic exists to end.
