## Plan changes made by this validation

1. **AC2.11 added to S4** — NFR3 had no acceptance criterion (dimension 2).
2. **AC5.6 added to S5** — the `B72` fix could make linear projects unopenable, which is `B42`'s
   failure mode and M5.E13's REVIEW Critical (dimension 7).

3. **AC1.2′ rewritten, AC1.2″ added** — a bare phase-name strip merges only **3 of the 4** measured
   split pairs. `PLAN-SLICE-VOICE1-*` strips to `SLICE-VOICE1` while its sibling is `VOICE1`, and
   `SLICE-` cannot be stripped unconditionally because `SLICE-SSO` *is* a canonical unit name. The
   rule became two passes — strip, then fold into an independently-derived unit. A test asserting
   only `GATE-A` would have shipped `VOICE1` still split.
4. **AC1.7 corrected to AC1.7′** — "byte-identical findings" was unachievable; the 8-suffix list
   genuinely derives more units on 3 projects.

All four are folded into `M5.E18-PLAN.md`. **40 ACs, 62+ tests, 18 RED-first.**

*Both late corrections were found by checking a claim the plan asserted rather than measured — the
same move that produced every finding in RESEARCH. Recorded because "the plan said so" is not
evidence, and two of this plan's own ACs were wrong until something executed them.*
