# M6.E12 — Plan: priorities, not age

**Goal:** `/sig:advise` and `/sig:drive`'s pick step propose 3–5 big-picture priorities from a cited
digest of the project's docs, ask the user to pick, record the pick, and offer to start it — with age
removed from every ranking.

Requirements: [`M6.E12-REQUIREMENTS.md`](M6.E12-REQUIREMENTS.md). Research:
[`M6.E12-RESEARCH.md`](M6.E12-RESEARCH.md). Node 22+ assumed; dev machine 22.13; no new dependencies.

## What this Epic does for the first time — wave 1

**A model synthesizing a project's priorities from Signal's own digest, through a code-checked
contract.** Nothing in Signal has ever handed the agent a structured picture of a whole project and
then validated what it proposed. The digest's shape, its size, and whether the contract is one a
real proposal can satisfy are all unknown until it runs. **So S1 ends with a real run on this
repository** — the digest built, priorities proposed from it, validated — before the artifact,
recording or drive work depends on the shape.
