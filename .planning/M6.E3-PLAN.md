## Phase goal

When a TypeSafe key is set, `/sig:resume` and an Epic-close SHIP show every `STATE.md` paragraph Jev
judges to contradict the project's facts, quoted beside the fact it contradicts. SHIP refuses a close
on code-proven stale records, and never on Jev's judgment alone.

---

## What this Epic does for the first time — scheduled in WAVE 1

1. **The SHIP gate refuses on what a document SAYS.** Every halt `ship.md` can produce today is a
   precondition failure; `runDriftChecks` appears nowhere in it (`RESEARCH` Finding 7). The gate this
   points at has a bad record: `B36`, three Epics silently inert. **→ `t2.1` is wave 1**, proven
   against fixtures before any real check can produce a finding for it to refuse on.
2. **Signal's shipped code calls a third-party model.** No code under `plugin/` has ever read an API key or
   called anything but GitHub and git. **→ `t1.3` makes a live call in wave 1** (the smoke step), so
   a wrong request shape or a retired model is found on day one rather than when `/sig:resume` first
   runs it.
3. **The network audit is used for its real purpose**, vetting a new call — and on first use it was
   found never to have scanned shipped code (`B125`). **→ `t1.2` is wave 1**, ahead of the client it
   must see.

## Decisions taken at PLAN (plumbing; recorded as `D-M6E3-13`)

| Item | Choice |

Supersedes the letter of `D-BR0925-3` (which kept the spike's calling script out of the repo so it would not escape the audit — with `B125` fixed and the call living in audited `lib/jev.js`, that reason no longer applies). |

### S1 — the Jev `STATE.md` check, shown at `/sig:resume`

#### `t1.1` — the receipt contract · **M**
- **Covers:** `AC1.1`, `AC1.2`, `AC1.3`, `AC1.4`, `AC1.5`, `AC9.4`.
- **Does:** a finding may carry an optional `receipt` `{claim:{file,line,excerpt}, evidence:{source,line|sha,excerpt}}` and an optional `judgedBy` `{model, confidence}`. A constructor rejects a receipt missing either side (`AC1.5`). One exported `refusableFindings(report)` returns only findings that have a receipt **and** no `judgedBy` — the single path any refusal may use (`AC1.4`, `AC9.4`). `renderReceipt` ≤ 15 lines, excerpts one line each (`AC1.3`).
- **Tests (RED first):** a receiptless finding and a `judgedBy` finding are both absent from `refusableFindings`; a half receipt throws at construction; render length pinned.
- **Files:** `plugin/tools/lib/receipt.js` (new), `plugin/tools/lib/state-drift.js` (pass-through of the two optional fields at `306-314`), `tests/receipt.test.js`.
- **Out of scope:** changing any existing check's output; any refusal wiring (that is `t2.1`).

#### `t1.2` — `B125`: the audit scans shipped code and knows its calls · **S**
- **Covers:** `B125`; `AC8.5` (audit half).
- **Does:** scan `plugin/` too; add a pattern that catches the injected-fetch idiom (`fetch` as an identifier/default, not only `fetch(`); an explicit allowlist of `{file, symbol}` — `plugin/tools/lib/doctor.js#fetchLatestTag` today. Anything else found → exit 1.
- **Tests:** the default run exits 0 **because** the one call is listed (assert the listing, not just the code); a seeded **unlisted injected fetch** exits 1; the existing seeded raw `fetch(` still exits 1. Correct `tests/sweep.test.js:409-421`'s comment and assertion so it checks what it claims.
- **Files:** `tools/audit-network-calls.js`, `tests/audit-network-calls.test.js`, `tests/sweep.test.js`, `tests/fixtures/audit-network-calls-seeded/`.
- **Out of scope:** scanning npm dependencies.

#### `t1.3` — the Jev client, and one live call · **M**
- **Covers:** `AC8.1`, `AC8.2`, `AC8.4`, `AC8.7`; `AC8.5` (allowlist entry).
- **Does:** `plugin/tools/lib/jev.js` — `askChoice({state, question, fetchFn = fetch, key = process.env.TYPESAFE_API_KEY, model, timeoutMs})` in `fetchLatestTag`'s shape. It returns `{ok:true, choice, confidence, probabilities, model}` or `{ok:false, reason}`, where the reason is one of `no-key | unauthorized | invalid-request | rate-limited | overloaded | timeout | network | bad-response`. It never throws, and the key never appears in a reason, error or log. Add `jev.js#askChoice` to the audit allowlist.
- **Live smoke (wave 1, required):** one real request through `askChoice` with the spike's question on one known paragraph (para 23 at `3518c11`), result recorded in `M6.E3-RESEARCH.md` as an addendum. **If `TYPESAFE_API_KEY` is absent at EXECUTE: ask Brett once for it, and HALT this step until it is set.** Never record "smoke passed" without the call.
- **Tests:** every status code → its reason; timeout → `timeout`; malformed body → `bad-response`; the parser accepts both the documented response shape and the spike's stored answers; a test asserts the key string is absent from every returned object. No test touches the network.
- **Files:** `plugin/tools/lib/jev.js` (new), `tests/jev.test.js`, `tools/audit-network-calls.js` (allowlist).
- **Out of scope:** retries/backoff (one attempt; a 429 is reported, not retried).
