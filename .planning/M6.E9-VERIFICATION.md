## FR3 is NOT EXERCISED, and that is the honest word

No agent was cut, so **no code path in this Epic ever removed a file**. Reporting FR3 as passing
would be a vacuous pass — the requirement's condition never arose. The nearest call was
`codebase-mapper`, deliberately left `dormant` with `cut` recorded as the live alternative.

**What this means for a future `cut`:** nothing in the suite checks that a cut agent's file is
actually gone. That guard does not exist, because writing one with no cut verdict to test it against
would itself be untested. Recorded here so the first real `cut` knows it is also building the check.

## FR5's nuance, stated rather than rounded up

`plugin/commands/plan.md` no longer *instructs* anyone to spawn the four named agents — the section
now describes research **angles** and says explicitly they are not agents. But the strings
`Domain researcher`, `Risk researcher`, `Prior art researcher` and the sentence
`spawn up to 4 research agents in parallel` **still appear in the file**, at lines 147–148, inside a
quotation of what the section used to say.

That is deliberate: deleting the old wording deletes the record of a defect that survived months in
the phase every Epic runs. It is written up rather than glossed because **a naive grep for those
strings still hits**, and someone should not later read that hit as a regression.

## ⚠ Three times this Epic, the CHECK was wrong and the artifact was right

This is the Epic's own finding, and it happened once more during VERIFY.

1. **DISCUSS** — a dispatch count of 6 was reported and briefly called a false positive in
   `agent-reachability.test.js`. The real rule requires backticks plus `subagent_type`; the repro
   used a bare-word regex. Page correct, check wrong.
2. **EXECUTE** — the new FR7 guard bound to `verifier.md` and `nyquist-auditor.md` where the page's
   *historical prose* quotes them, not where their verdicts are. `B109`'s first-match shape. Fixed by
   scoping to the determination region.
3. **EXECUTE** — the first RED-first proof used shell-escaped one-liners whose backticks did not
   survive quoting. The mutation silently no-op'd, the suite passed, and that was briefly read as
   *"both new guards are vacuous."* They were not.
4. **VERIFY** — the FR6 check reported `nyquist-auditor` and `verifier` as double-listed. Same cause
   as (2): it read the whole page instead of the determination region. Scoped, it reports 0.

**All four are the same defect: a re-implementation of a rule, checked against the artifact, where
the re-implementation was the thing that was wrong.** The artifact was correct every time. That is
worth more than any individual fix here, because the Epic's entire subject is a page whose accuracy
nothing could confirm.
