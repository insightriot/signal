## What is genuinely NOT already built

Stated so the disposition is a choice between real options rather than a cut.

1. **A trigger.** `auditor`'s judgement is intact; *its trigger is what lapsed* — it is invoked by a
   person remembering. `B39` is this repo's standing finding that **Signal's triggers have never
   once been walked.** Nothing schedules a corpus sweep.
2. **Signal-specific corpus semantics.** `/prose:backlog` does not know what a *trigger*, a
   *disposition stamp*, an *Epic ID*, or a *closed milestone* is. `F1` and `F4` required exactly
   that knowledge; a generic reviewer would not have found either.
3. **Landing the result.** The review *"changes nothing on its own"* (`D-M5E18-1`), so every pass
   needs a person to transcribe recommendations into `BACKLOG.md`. That is the repeatability gap the
   Epic was actually named for.

**⚠ Automatic selection stays OUT, on measured evidence.** `LOOP-GOAL-DIRECTION.md` measured the
best honest selection rule over these real rows at **77% precision / ~37% recall** and recommended
not building it. Nothing here changes that; the advisor proposes and cites, and a person picks.

## Disposition: **C — build it as specified** (`D-M6E7-2`)

**Chosen 2026-09-05.** B (reshape small) was recommended; C was chosen, and the reason the Epic
exists changed with it.

**The justification is no longer capability. It is not wanting a cross-plugin dependency.** `/prose:`
is a separate plugin that must run in any repo, including one with no `.planning/` and no Signal
install. Coupling a first-party Signal flow to something a user need not have installed is a real
cost, and avoiding it is a legitimate reason to build a second implementation. It is a *different*
reason from the one `BACKLOG.md`'s row gives, and it is written down here so the next reader is not
told the capability was missing.

⚠ **The cost this buys is duplication, knowingly.** The check that `BACKLOG.md`'s own row demands —
*"check first, size second"* — was run first and is recorded above. Its rule was followed; its
conclusion was not.

**Q2 is moot** under C: there is no dependency to degrade gracefully around. **Q3 is answered by the
row's own done-when** — *"a stranger runs it"* — so the trigger is a `/sig:` command invoked on
demand, not a hook or a schedule. `B39` is satisfied by a trigger a person actually walks rather than
one that exists in prose.

**Tier: FEATURE** ([`M6.E7-PROFILE.md`](M6.E7-PROFILE.md), `D-M6E7-3`), derived from the ordered
gates, with one override — `nyquist_enforcement: strict`, because citation-resolution must not be

**Working name: `/sig:advise`. Provisional.** The row says *"naming deliberately open — do not fix

## Functional requirements

- **FR1 — Read the corpus it advises on.** `BACKLOG.md` rows, `BUGS.md` rows, the retrospective
  corpus, and the state that says what is open or closed (`STATE.md`, the milestone files). Reuse
  `parseBacklogRows` and `walkBugEntries` rather than re-parsing — a second copy of a parser drifts,
  which is `#230`'s finding.
- **FR2 — Return the top N with *why this and not that*.** Each recommendation carries a reason, and
  each reason names what in the corpus makes it so.
- **FR3 — Every claim carries a citation that resolves.** A path, or `path:line`. This is the Epic's
  load-bearing property.
- **FR4 — A declined section: what was considered and NOT recommended, with the reason.** `B39` is
  this repository's standing rule that a **checked-and-declined item must be distinguishable from an
  unchecked one**. Signal has its own reason for this section; it is not borrowed.
- **FR5 — Read-only.** Emits an artifact. Never edits `BACKLOG.md` (`D-M5E18-1`, `D-M6E7-4`).
- **FR6 — Proposes, never selects** (`D-M6E7-4`; `LOOP-GOAL-DIRECTION.md` measured 77% precision /
  ~37% recall and recommended against automatic selection).
- **FR7 — A source it could not read renders as `cannot-check`, on its own line, never folded into
  "nothing found."** The same posture `/sig:ship`'s review-findings and `/sig:drive`'s preflight
  already take. An advisor that silently skipped `BUGS.md` and reported a clean queue would be
  worse than one that refused to run.

## Non-functional requirements

- **NFR1 — Offline and deterministic in its reading.** No network. The same corpus produces the same
  citations.
- **NFR2 — No dependency on the `prose` plugin.** This is `D-M6E7-2`'s whole point; a test should
  fail if one appears.
- **NFR3 — No new dial.** Ranking weights are not a `PROFILE.md` field. A fourth knob is `B75`.

## Acceptance criteria — the citation test is the one that matters

- **AC1.1** — Given Signal's own `.planning/`, the command emits an artifact with at least one
  recommendation and at least one declined item.
- **AC1.2** — **Every citation in the emitted artifact resolves**: the path exists, and where a line
  is given it is within the file. Checked mechanically over the whole output, not sampled.
- **AC1.3** — A citation that does **not** resolve fails the run loudly rather than being dropped —
  proven by mutation, i.e. injecting a bad citation must fail the check.
- **AC1.4** — With `BUGS.md` unreadable, the output names it under `cannot-check` and does **not**
  report an empty or clean bug set.
- **AC1.5** — The command writes no file outside its own artifact; `BACKLOG.md` is byte-identical
  before and after.
- **AC1.6** — No import of, or shell-out to, anything under the `prose` plugin (NFR2).

## Outcome oracle — how we will know it *worked*, not that it is done

**Primary:** *the next backlog review on this project is generated rather than hand-written, and the
person acts on it.* That is the outcome the row asks for — repeatability replacing a one-off manual
pass — and it is observable: either a `BACKLOG-REVIEW-*.md` appears with the command named as its
producer, or the next pass is hand-written again and the Epic did not land.

**Calibration check, secondary and deliberately not a pass/fail gate:** run it against the frozen
[`BACKLOG-REVIEW-2026-08-09.md`](BACKLOG-REVIEW-2026-08-09.md) and report how many of that review's
**top three moves** appear in the advisor's output with resolving citations.

⚠ **A miss there is informative, not fatal, and saying so in advance is the point.** That review's
best content came from cross-document contradiction finding, which FR1–FR7 do not attempt; scoring
low would tell us the ranking half was the less valuable half — which is a finding worth having, not
a failure to explain away. Recording the expectation now is what stops the number being
rationalised after it arrives.
