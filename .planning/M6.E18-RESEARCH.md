## 1. Domain — the PR reviewer and its on-demand run

- **Step 1 is the stop.** `plugins/code-review/commands/code-review.md` (anthropics/claude-code) step 1
  ends *"Claude has already commented on this PR … If any condition is true, stop and do not proceed."*
  The command takes only `--comment`; there is no force option. [V]
- **What #304 actually got.** Ten reviewer runs. The first (`e92032de`, run 39316819152): 9 turns,
  $1.44, posted "No issues found" at 20:13. The other nine stopped at step 1 in 2–4 turns; run
  39346376038's result text: *"Claude has already commented on PR #304, so I'm stopping."* [V]
- **The action checks the actor.** For `pull_request*` and `issue_comment` events it requires `write`
  or `admin` (`src/github/validation/permissions.ts`); bots pass. [V]
- **Trigger choice: `pull_request` `labeled`.** It is a PR context (the inline-comment tool is
  installed) and its run carries the PR head sha, so `gh run list --commit <head>` finds it.
  `workflow_dispatch` is not a PR context (`src/mcp/install-mcp-server.ts:150-155`) and its sha is the
  dispatched ref's [I]; `issue_comment` runs on the default branch's sha [I]; a plain re-run replays
  step 1. [V except where marked]
- **`labeled` fires only on add.** Re-asking is remove-and-re-add. Removing the label from the job would
  need `pull-requests: write`; the job keeps `read` (`D-M6E18-8`).
- **Getting past step 1:** fork the prompt (steps 2–9 inline, pinned to the upstream commit) — the only
  option that removes the check. An appended "ignore step 1" sentence argues with it; minimizing the
  earlier comment is untested and judged by a haiku agent. The action restores `.claude/` and
  `CLAUDE.md` from the base branch on PR events (`run.ts` ~263), so the fork lives inline in the
  workflow, not as a repo command. [V]
- **The workflow-edit refusal** happens on Anthropic's token-exchange server; the action logs
  *"Skipping action due to workflow validation"*, conclusion **success**, no result block (run
  37524298235). `readReviewerEffort` reads that as cannot-check today. [V] Hence `D-M6E18-7`.
- **The log has no result text.** Without `show_full_output` it carries `num_turns`, `total_cost_usd`,
  `permission_denials_count`, not `result` (`base-action/src/run-claude-sdk.ts:117-160`). The
  transcript artifact (`claude-execution-output.json`, last `type:"result"` entry: `result`,
  `num_turns`, `subagent_stats`) is kept one day. So the job writes a `REVIEW_OUTCOME=` line into the
  log from the artifact, in an `if: always()` step. [V]
- **Identifying the on-demand run:** `run-name` shows as `displayTitle` in `gh run list --json`
  [I, GitHub docs from memory]; `event` stays `pull_request` [V]. `readReviewerEffort` lists more than
  one run per head commit (today `--limit 1`).

## 3. Risk

- **A visit marker that drifts from `phase_passes`.** If a marker records a length and the list is
  later trimmed (linear SHIP clears it, an Epic roll resets it), a stale marker could exceed the list.
  Rule: a marker greater than the list length is unreadable → `null` → `loop-unknown`. Cleared wherever
  `phase_passes` is cleared.
- **The forked prompt drifts from upstream.** Pinned, with the commit in the comment; a contract test
  asserts the fork has no "already commented" condition and still names the four review agents.
- **Git in `checkFixRounds`.** Resolving a sha adds a git call to a pure parser. Inject the exec, and
  route through the hardened git environment the other git readers use (`tools/lib/git-env.js`), so a
  hostile `.git/config` cannot run commands (`SIG-313`'s class).
- **The driven run executes the installed release, not this branch.** `/sig:drive` and the phase
  commands load `~/.claude/plugins/cache/signal/sig/0.1.52/`. For the outcome to be measured on this
  Epic, VERIFY and REVIEW's state calls must use this branch's `plugin/tools/lib/` once S2 lands. Said
  in the plan rather than discovered at REVIEW.
- **Doc-contract tests.** `review-loop-doc-contract` and the adherence ceiling read `commands/*.md`;
  every edit there moves them (`D-M6E18-5`).
