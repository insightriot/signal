## Deviations — the criteria that changed

**D1 — AC1.2 re-scoped before implementation.** Draft demanded a halt on a *non-null but
unresolvable* `current_epic`. That contradicts `detectMode`, which fail-opens malformed and
version-string values to linear by ratified design (D-E11-4). Requirements updated first.

**D2 — FR2 redesigned at Wave 2 entry.** Recording the phase *entered* would have made
`completed_phases` list an in-flight phase, breaking `resume.js`'s count and firing
`isEpicCloseByState` a phase early. `B43`'s real defect is that **SHIP is terminal** — the fix
is an addition (`completePhase`), not an inversion.

**D3 — AC5.5 caught a real defect.** The first trim implementation broke its own idempotence:
the trim empties the live list, erasing the evidence the same-day guard reads. **Only visible
because idempotence was speced rather than assumed.**

**D4 — AC7.3 replaced, not met as written.** Widening the migrate predicate re-flags the
residue that same vector leaves (B12's deliberate short-label design), so
`applyDeproseVector1` stopped converging — its own idempotence test killed it. Repair moved to
the write seam, where it is automatic and idempotent. **Sweep's message was corrected to match;
it had been pointing at a command that would not have fixed it.** *The AC's intent (a repair
path exists) is met; its letter (a migrate vector) is not.*

**D5 — NFR2 was violated by my own FR4 code.** `partitionCompletedPhases` dropped malformed
entries and merely *returned* them, so a caller ignoring the return value destroyed them —
a smaller copy of the bug this Epic exists to fix. Now archived verbatim before the write.

**D6 — a duplicate export crashed the shipped hook while the suite was green.**
`export const PHASES` collided with an existing export at the foot of `state.js`. `vitest`'s
transform tolerated it; `node` did not. **Caught only by the spawn tests.** Reverted. *Recorded
because it is a real gap between how the suite loads modules and how the runtime does.*
