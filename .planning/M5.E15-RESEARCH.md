## 6. `D-M5E15-5` does not land as written — measured, and it is now `B81`

`tests/guard-callers.test.js` auto-discovers guards with one regex,
`argv.includes('--flag')` (`:76`). `tools/` uses **three** argv idioms:

| Idiom | File | Flags |
|---|---|---|
| `argv.includes('--x')` | `adherence-ceiling.js` | 1 — **the entire governed population** |
| `a === '--x'` in a loop | `adherence-run.js` | **12** |
| `args.includes('--x')` on a slice | `cut-release.js:41` | 2 |

Re-running the test's own `findCliGuards` + `hasCaller` with all three patterns: **1 → 25 flags
across 8 files, 10 with no caller, every one in `adherence-run.js`.**

So the file M5.E15 modifies contributes **zero** flags to the population the mechanism governs, and
registering the leak check there would have appeared to work while checking nothing.

**The naive widen is wrong and this Epic does not do it.** The 10 orphans are mostly *options*
(`--runs`, `--keep`, `--transcripts`, `--arm`), not *guards*, and the test has no written definition
separating a flag that gates behavior from one that carries a value. Its stated population ("CLI
guards") and its detected population (one idiom) are wrong in **opposite** directions. Filed as
**`B81`** (P2, `confirmed`); FR5 uses a **bespoke named assertion** — `B54`'s shape, already the
precedent in that file — instead.

## Risks

1. **The re-run costs real time and may return `INDETERMINATE` again.** Pre-declared reading in
   `D-M5E15-9` / AC6.5 — *multi-homed beyond isolation*, and explicitly **not** an auto-escalation to
   corpus scope.
2. **Widening the deletion to five files widens the blast radius of a wrong anchor.** Mitigated by
   AC1.3 (every anchor asserted to occur exactly once against the live corpus) and AC1.5 (a section
   anchor that is not its own discrete section fails a test).
3. **The descriptive allowlist is a static list, which is `B55`'s own shape.** Mitigated by direction:
   the list is *fail-closed* — unknown sites are treated as directive and **stop** the run. A stale
   allowlist breaks loudly; the thing `B55` did was fail open.
4. **`INDEX.md` regenerates on every `transitionPhase`**, so phase transitions produce doc churn in
   the same commits. Expected, not drift.
