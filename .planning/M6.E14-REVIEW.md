## Security Findings

`security_audit: full`, threat model as M6.E12 named it: a cloned repository and a pushed branch are
untrusted input.

- **Symlinks:** `linkedComponent(..., {from})` skips only an exactly matching leading `.planning`;
  every component below it is still `lstat`-checked; `assertRealInsidePlanning` refuses a `.planning`
  outside the project, at the project folder itself, or in `.git/`. The migration keeps the full check.
  Pinned by direct `confineView` tests and a mutation check (VERIFY).
- **Git invocation:** proofs match `^[0-9a-f]{7,64}$` before any git call; `--disambiguate=<hex>`
  cannot carry an option; object ids come from git's own output and follow `--end-of-options`;
  `execFileSync`, no shell, `cwd` is the project, stderr ignored.
- **Reads of attacker-shipped files:** `WATCHLIST.md` and now archived READMEs read only as regular,
  unlinked files inside the project (Important 1).
- **Error text:** messages echo IDs, relative paths and the proof; after Important 1, none can echo
  file content.
- **Inputs at boundaries:** `newItems({dedupeBy})` accepts only `'source_ref'`; anything else is a
  SCHEMA refusal with nothing written. Secrets scrubbing unchanged.
- **Dependencies:** none added. **Headers / CORS:** not applicable — no server.
