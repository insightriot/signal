## 5. What VERIFY caught: AC4.1 was unmet — loop-back A, fixed, re-verified

**Goal-backward analysis was made this phase's first question, and it earned its place.**

A per-symbol reachability sweep over every new export found the wiring correct for nine of ten —
`deriveUnits`, `currentUnit`, `parseVerdict`, `rankTerminalArtifacts`, `resolveClosures`,
`explainArchiveOutcome`, `deriveUnitArchiveDir`, `isSafeUnitName`, `retroStatusFromContent` all
reach a user-facing command. *(The first run of this sweep reported four false "NO PRODUCTION
CALLER" results because the exclusion list removed `closure.js` for symbols it legitimately consumes
— corrected before anything was concluded from it.)*

**The real finding came from the shape of the wiring, not the sweep.** `renderDryRun` gated the
explanation on `archive.moves.length === 0`, so a project with **real moves AND an unevaluable unit**
printed a bare count and said nothing about the unit needing a person. Constructed and confirmed:

```
  archive-tree moves:   2          ← 1 unit was cannotDetermine; nothing said so
```

**That is `B63`'s own class surviving inside the fix for `B63`** — and `AC4.1` requires the
`cannotDetermine` count be reported, not merely reported when convenient. It did not surface on the
12 real projects because none currently has moves > 0 *and* an unreadable unit — **inventory luck,
the same thing this Epic keeps naming.**

**Cause:** the caller re-implemented *"is this number ambiguous"* instead of letting
`explainArchiveOutcome` decide — a duplicated rule, which is the `isStubRetro` defect one layer up.
**Fix:** the condition is gone; the renderer returns `[]` when there is nothing to say. Now:

```
  archive-tree moves:   2
  ↳ 1 further unit(s) could not be evaluated and are NOT included above:
      T25 — T25 has 1 terminal artifact(s) but none states a readable verdict
```

**Cost measured, not estimated:** `resolveClosures` now runs on every dry-run — **3.2 ms, 1.4 % of
`renderDryRun`'s 234 ms** on Signal's own tree. *(A first attempt to measure this compared two
separate node processes and reported the instrumented path as **faster** than the baseline; that was
filesystem-cache noise, discarded, and re-measured in one process.)*

Regression test added for the exact shape. **2154 → 2155.**
