# M5.E16 — Epic-scoped calibration

**FEATURE, not the project's FULL.** New read-only checks inside an existing read-only command.
No new command, no schema change, no network, no writes, no security boundary. Every change is a
`git revert` away from undone.

**Why the overrides, individually:**

- `research_parallelism: 0` — nothing to research. The bug evidence is already catalogued: 20 of
  56 entries in `BUGS.md`, and the failure shapes were sorted at the design conversation that
  opened this Epic.
- `security_audit: none`, `performance_pass: false` — read-only string and file-existence checks
  over a local directory. No attack surface. (Performance gets a floor in **NFR3** instead, because
  a slow sweep is a sweep nobody runs — but that is a budget, not a profiling pass.)
- `plan_validation_dims: core` — the scope is bounded and the dependencies are shallow.
- `review_depth: quality-only` — no security/perf panel for a detector.
- `gate_strictness: light` — confirm at phase close, not at every step.

**What is NOT relaxed, and why `nyquist_enforcement` goes to `strict`:**

`tdd_required: true` and `simplification_pass: true` stay on, and **Nyquist goes to `strict` — a
level above M5.E17's `basic`.** This is deliberate and it is the one dial that matters here.

The risk this Epic carries is **not** that a check fails to fire. It is that a check fires when it
shouldn't. A detector with false positives gets muted within a week, and a muted detector is worse
than no detector — it looks like coverage. `strict` demands the proof-of-fail record: every check
ships with a fixture proving it goes red on real drift **and** a fixture proving it stays silent on
a clean project. **Precision is the deliverable; recall is secondary.**

**Escalate if:** the checks cannot reach acceptable precision without a semantic judge (which would
break `/sig:sweep`'s offline + deterministic contract and make this a different Epic), or if any
check turns out to need a `.planning/` schema change rather than reading what is already there.
