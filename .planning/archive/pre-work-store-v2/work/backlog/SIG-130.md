## Archived phase logs are written but never staged

**Status:** needs-triage

Archived phase logs are written to disk but never staged, so an Epic's ledger survives the roll and then never reaches the repo. Found 2026-08-19 by `git status` at the M6.E3 PLAN entry, not by any check. Both Milestone 6 archives were untracked: `.planning/archive/M6/E1/STATE-NARRATIVE.md` (written 2026-08-18, orphaned since v0.1.26) and `.planning/archive/M6/E2/STATE-NARRATIVE.md` (written during the M6.E3 roll). Neither is gitignored, and every M4.5 and M5 archive IS tracked, so this is a staging gap, not a policy. `commands/ship.md` §5.5 says the evicted narrative is "staged into the SHIP commit" and §6/§6.5/§6.6/§8 say the same for their artifacts; for M6.E1 and M6.E2 that did not happen, twice in a row, and nothing noticed. THE SHARP EDGE: `.planning/INDEX.md` IS tracked and committed, and it links to both files — lines 292-293, `archive/M6/E1/STATE-NARRATIVE.md` and `archive/M6/E2/STATE-NARRATIVE.md`. So the repository publishes an index pointing at two files that do not exist for anyone who clones it, and `/sig:index` regenerated those rows from the working tree without ever asking whether the target was in the repo. WHY IT MATTERS BEYOND TIDINESS: this is `B52`'s harm reached by a different route. The `setCurrentEpic` guard correctly refuses to zero an unarchived phase log, the archive gets written, and then nothing carries it into version control — so the ledger exists on exactly one disk. The maintainer works on one machine, so an untracked archive is one disk failure from gone, and the guard that exists to prevent silent ledger loss reports success. FIX SHAPE, NOT YET DECIDED: either the eviction path stages what it writes, or a check asserts that every path `INDEX.md` links to is tracked — the second is the more general one and would catch any future write-then-forget, not just this one. The first is smaller. Note the second is a closed-list absence check (the list being INDEX.md's own links), which is exactly the shape `M6.E3` `D-M6E3-2` says absence is provable against.
