# M6.E13 — Validation map (Nyquist)

Every acceptance criterion maps to a test type and to the task that writes its test, so the
criterion is tested by that task's own TDD loop. Strict mode: each test must be seen failing before
the code that passes it is written, and VERIFY checks for that.
