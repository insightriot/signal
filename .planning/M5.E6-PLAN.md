## Architecture Decisions (locked at PLAN)

1. **`/sig:sweep` logic lives in a unit-tested `tools/lib/sweep.js`; `commands/sweep.md` is a thin driver.** Command markdowns have zero mechanical coverage (`validate-plugin.js:108-113`), so the logic must be testable in a lib. Read-only, `runSweep(process.cwd())` entry, no arg parser (v1).
2. **`doc-hygiene.js` refactor is additive parameterization only** — every export keeps its `baseDir = ROOT` default so `tests/docs-hygiene.test.js` stays byte-identical. Sweep passes scope/`stripCode` opts.
3. **Portable-vs-Signal split lives in `sweep.js`, not `doc-hygiene.js`** — and the **stale-inbox check must live in `sweep.js`** (the guard's meta-test greps its source for the forbidden inbox-name token `/FUTURE-IDEAS|ISSUES-INBOX/`, docs-hygiene.test.js:267).
4. **Index-freshness uses the pure compose-and-diff path** (`enumeratePlanningDocs`→`renderPlanningIndex`), never the writing Core (AC2.1 / AC1.5).
5. **Stranger-repo INDEX gating (PLAN decision):** index drift is **structural only when the on-disk `INDEX.md` carries the autogen marker AND has drifted**; a foreign/hand-written INDEX (`isForeignIndexFormat`, planning-index.js:131) or an absent one → **advisory**, not structural — prevents stranger-repo noise.
6. **CLAUDE.md bloat threshold (PLAN decision):** new named const `CLAUDE_MD_BLOAT_BYTES = 40 * 1024` in `sweep.js` (current CLAUDE.md ≈ 13.5 KB → headroom). Coarse advisory only — NOT `STATE_SIZE_WARN_BYTES` (STATE accretes history; CLAUDE.md loads every turn).
7. **FR5 = approach (c) as in-memory synthesized state, persist nothing** (D-M5E6-5) — fix inside `shipFR1Check`; `isEpicCloseByState` + `ship.md` byte-unchanged.
8. **FR4: B27 ≠ B28** — B28 is a correctness fix in `computeLinkEdits` (skip absolute), B27 a policy exemption in `partitionDangling`. AC4.4 flag gets its own dry-run line.
9. **FR6 guard = `Object.hasOwn + typeof`**, not Symbol (Symbol changes the B25 test).
10. **FR7 = close-out + B31** (D-M5E6-5): the lock is already built; add's doc-write moves under `.state.lock`, prompt stays outside under `.add.lock`.
