# M1.E4 Requirements

The coverage-gap shape. Four requirement IDs are declared here; the matching
VERIFICATION names two of them.

- FR1 — the login form submits.
- AC1.1 — a valid credential pair is accepted.
- AC1.2 — an expired session is rejected.
- NFR1 — the check runs offline.

`NFR1` is the one that matters. Before M5.E10 the extractor's `\bFR\d+` pattern
could not match it at all, so a coverage report would have called this pair
complete while never having looked at the non-functional requirement.
